keyboard shortcuts

Press ! or F1 on the dashboard for the searchable live list (also Config → Help → Keyboard). :cheat and :help open the same modal. This printable sheet is generated from the same source.

Navigation

1–9Switch to bookmark page
Shift+IOpen Inbox — links saved to read later
Shift+HOpen Health — bookmarks that need attention
Shift+SOpen config — settings, pages, and bookmarks (with no bookmark selected; on a selected row it shares instead)
Shift+←/→Previous / next page
,Page overview with bookmark counts
!/F1This cheat sheet
↑ ↓ ← →Move focus up / down through bookmarks
Enter/SpaceOpen focused bookmark
EscClear selection / close overlay; undo unsaved drag reorder

Bookmarks

Shift+PPin or unpin the focused bookmark
Ctrl/Cmd+EnterOpen the focused bookmark in a new tab, whatever the open-in-new-tab setting says
Shift+SShare the focused bookmark, or copy its name and URL where no share sheet exists (with nothing selected the same key opens config)
Shift+ROpen the focused bookmark on its own row in Health
tFilter the grid to the focused bookmark’s tag; several tags open the picker

Selecting several bookmarks

xTick the focused bookmark and move to the next — so a run of rows is x-x-x
XTick every bookmark in the focused category

Health view

j/kMove between rows (↑ / ↓ work too)
sUnfold the score breakdown for the selected row
iOpen uptime statistics for the selected row
pRe-check the selected bookmark now
fWork through the filtered list one bookmark at a time, starting at the selected row
R/?Refresh the cached health report
cChange availability checking — off, periodic or monitor
mRow menu — redirect, title, favicon, archive, delete
xTick the focused row for a bulk action
Enter/SpaceOpen the selected bookmark
g/G/Home/EndJump to the first / last row
EscClose a menu, or leave the view

Inbox view

j/kMove between rows (↑ / ↓ work too)
Enter/SpaceOpen the selected item
pPromote to a full bookmark
nAdd or edit a note
rMark as read
zSnooze until later
xToggle row selection for bulk actions
Shift+↑/↓Extend the selection to the next or previous row
Ctrl/Cmd+ASelect every link currently shown
dDelete the selected item
RReload the list from the server
g/G/Home/EndJump to the first / last row
tOpen triage — walk the list one item at a time
EscClear selection, or return to bookmarks

Inbox triage

j/kMove to the previous / next item
o/EnterOpen the current item
pPromote to a full bookmark
r/SpaceKeep and mark as read
zSnooze until later
nAdd or edit a note
dRemove the current item
EscClose triage

Config view

j/kPrevious / next section in the left rail
[/]Previous / next sub-tab in the current section
Ctrl/Cmd+Shift+KFind a setting, section, or help topic
Shift+S/<Return to the dashboard from config
EscClose bookmark editor, clear list selection, or exit config

Search modes

>Regular search — filter bookmarks on current page by name
:Command palette — type a command name to run it
?Finders — e.g. ?g query to search Google
*Recent bookmarks panel

Commands — navigation
